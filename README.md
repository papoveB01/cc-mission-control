# cc-mission-control

Live dashboard for Claude Code sessions: agents, subagents, context usage, and tool calls in real time.

Work in progress (v0.1 under construction). See `SPEC.md` for the build specification.

## Install

```
/plugin marketplace add papoveB01/cc-mission-control-beta
/plugin install cc-mission-control@papoveb01
```
